# 🕒 Horário Dinâmico - Sistema de Saudação e Interatividade Temporal com JavaScript

## 📌 Visão Geral do Projeto
O **Horário Dinâmico** é uma aplicação web interativa em JavaScript puro (Vanilla JS) que captura o horário em tempo real do sistema operacional do usuário e modifica dinamicamente toda a interface visual da página. O sistema calcula o período vigente (Manhã, Tarde ou Noite), injeta uma saudação customizada e altera os ativos visuais e paletas de cores de fundo de forma automatizada.

Projeto prático focado na manipulação de objetos temporais nativos desenvolvido durante a formação especializada na **OneBitCode**.

🔗 **Acesse a aplicação em produção:** [https://eduardocruz777.github.io/Horario/](https://eduardocruz777.github.io/Horario/)

---

## 🛠️ Tecnologias, Recursos Lógicos e Conceitos Aplicados
* **Objeto Nativo `Date` do JavaScript:** Uso de construtores de data e tempo (`new Date()`, `getHours()`) para extrair e tratar dados temporais diretamente do sistema do cliente.
* **Manipulação de Estados no DOM:** Desenvolvimento de lógica condicional (`if/else`) para realizar a varredura das faixas de horário e acionar a injeção dinâmica de dados na tela (`innerText` e `src`).
* **Design Responsivo Dinâmico (CSS3):** Criação de uma folha de estilos limpa, adaptável e preparada para responder aos gatilhos de transição visual disparados pela inteligência do script.
* **UX Contextual Avançada:** Implementação de experiência do usuário baseada em contexto ambiental real (Mudar fotos e iluminação da página com base no horário do dia do usuário), melhorando o engajamento visual.
